## 启动

需要 Node.js 24.12 或更新版本。

```powershell
cd F:\HoguLink
npm install
npm run dev
```

打开 [日语首页](http://127.0.0.1:3000/ja)、[English](http://127.0.0.1:3000/en) 或 [中文首页](http://127.0.0.1:3000/zh-cn)。本地 API 为 `http://127.0.0.1:4000/v1`。无需数据库安装，默认将 SQLite 文件保存到 `hogulink-api/data/hogulink.sqlite`，重启保留数据。

首次运行会创建 3 家虚构店铺、6 名插画人物、每店 60/90/120 分钟服务。可从页面上的演示登录按钮进入各角色。一个浏览器会话当前使用一个角色，切换角色会替换当前会话；多角色同时操作可用不同浏览器窗口或隐私窗口。

## 体验一笔预约

1. 顾客首页选择技师、服务、区域、语言和时间。也可选“不指定”，由店铺安排。
2. 点击演示顾客登录，创建报价和短时保留。结算页填写演示酒店地址，模拟支付认证，确认条款并提交。
3. 店铺 Nagi 为自动受理；Mori 为人工受理；Sora 为 SOLO 一键受理与任务确认。
4. 在技师端选择获派人员，确认工作任务，然后依次出发、到达。到预约开始时间后才能开始，服务足时后提交结束。
5. 顾客核对并确认完成后才演示扣款，再查看平台服务费或向原店铺申请退款。平台端可查看审计和安全队列、暂停/恢复展示。

可从 [店铺端](http://127.0.0.1:3000/zh-cn/merchant)、[技师端](http://127.0.0.1:3000/zh-cn/staff)、[平台端](http://127.0.0.1:3000/zh-cn/admin) 进入。这里的 SOS 仅写入演示队列，不会联系真实紧急联系人。

## 验证

```powershell
npm test
npm run build
# 另一个终端保持 npm run dev 运行后：
npm run smoke
# 第二轮售后与安全集成检查：
npm run smoke:care
```

`npm test` 使用独立内存数据库，不改本地演示订单。`npm run smoke` 针对已运行的服务执行 HTTP 与 SSR 集成检查，会创建一笔演示预约，完成并全额退款，保留审计记录。构建包括严格 TypeScript 检查。

`npm run smoke:care` 检查工单、店铺拒接、平台限制、申诉与安全处置，执行前要求演示顾客没有有效限制/拒接；脚本会清理自己创建的限制并免费取消自己的演示预约。当前465项后端测试、53项前端/会话规则测试；`npm run check` 包含全部518项测试、类型检查与生产构建。推荐 `npm run smoke:isolated`，在独立内存 API 执行四端预约、售后、员工权限、体验、消息、协作、监控、账单及商户方案，共1181项 HTTP/SSR 检查。

## 售后与安全

四端工作台新增“售后与安全”标签，顾客也可从每笔预约的“提交新问题”进入。普通服务问题先由本店处理，安全/资质/隐私等敏感问题直接提交平台。支持店铺答复、顾客升级、平台记录处理结果，以及提交人确认关闭或申请重新处理。

店铺只能设置本店顾客拒接，原因不共享；技师可提交仅本人和平台可见的安全反馈，审核期间暂停该顾客在本店的新预约。平台可设置期限明确的账号限制，顾客仍可申诉，审核通过后可解除对应限制。SOS 事件现在可以由平台记录处置结果；完成处置不会自动解除其他限制。

可打开 [顾客售后](http://127.0.0.1:3000/zh-cn/account/support)、[店铺售后](http://127.0.0.1:3000/zh-cn/merchant/support)、[技师私密反馈](http://127.0.0.1:3000/zh-cn/staff/support)、[平台处置](http://127.0.0.1:3000/zh-cn/admin/support)。这些记录只保存在本地；真实邮件、LINE 与紧急通知尚未接入。

## 配置与 PostgreSQL

按需复制 `hogulink-api/.env.example` 为该目录下的 `.env`，Web 配置复制 `hogulink-web/.env.example` 为 `.env.local`。调整后重启对应服务。API 环境文件由 Node 原生加载，Web 环境文件由 Next.js 加载。不要将真实凭据提交到仓库。

本机 Docker 已启动时可使用目标 PostgreSQL 适配器：

```powershell
docker compose up -d
# 在 hogulink-api/.env 中设置：
# DATABASE_URL=postgresql://hogulink:local_only@localhost:5432/hogulink
npm run dev
```

PostgreSQL 会建立 busy interval 排斥约束、预约身份不可变触发器及事务串行锁。当前通用 JSON 记录用于快速建立领域基线，生产数据库规范化、迁移版本管理和高并发优化仍在后续计划内。此次环境 Docker 引擎未启动，因此 PostgreSQL 适配器尚未经过实际运行验证。
