# 自动受理范围与预约接单（2026-10-19）

第二十九轮补齐 PRD 6.2、M10、CP-14/15 的本地业务规则。店铺从[店铺设置](http://127.0.0.1:3000/zh-cn/merchant?tab=settings)明确授权项目、技师、地区、每日服务时段、含指名费/交通费的总价范围和每日上限，可关闭即时预约、移除单个项目或立即暂停全部自动受理。

## 预约行为

| 条件                                             | 处理                                                                                                                                |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| 普通预约符合全部有效授权                         | 店铺自动受理，指定技师收到待确认任务；技师确认前不成为已确认预约                                                                    |
| 普通预约超出范围、达到上限、暂停或缺少旧数据授权 | REQUESTED / PENDING / NOT_SENT，转原店铺人工受理，再由技师确认                                                                      |
| 即时预约不符合有效授权                           | 不开放对应即时供给/时段，不创建新订单；报价、保留及提交时分别检查                                                                   |
| 不指名预约                                       | 在合格且有空的本店人员中优先保留授权范围内人员，保留原始 FREE 选择和店铺后续派发流程                                                |
| 付款认证后即时额度被其他订单占用                 | 返回 INSTANT_UNAVAILABLE，不创建订单或扣款；关闭最终核对，提示重新选时段，释放原保留/未使用授权后带回普通预约，保留项目、地区与语言 |
| 修改或暂停规则                                   | 推进店铺规则版本，使未提交的旧报价重新核对；已提交订单的受理结果、人员选择、费用、技师确认和售后继续按原订单办理                    |

时段按 JST 的同一服务日配置，起点 0–23 时、终点 1–24 时，起点必须早于终点，整段服务须落在窗口内。当前不提供跨午夜的单一授权窗口。每日上限按服务开始日期累计自动受理次数；取消、退款或之后修改规则不会返还已使用额度。最后一次检查与写入订单位于同一事务，并发提交不会越过上限。人工受理不消耗自动受理额度。

## 授权与追溯

- 开启或修改有效授权、从人工切回自动模式须明确勾选本店授权；暂停和关闭自动模式可直接执行。范围只能包含本店当前合格的项目、人员和地区。界面只改变选项排列时不产生新授权。
- 服务端填写授权人、时间与版本，保存 `acceptanceRules` 历史和订单 `acceptanceDecision` 快照。店铺可看最近五版及每笔订单提交时的处理原因。
- 公开目录不返回授权规则；顾客和技师的订单读取、提交重试及后续操作不返回完整授权快照或授权人。
- 存量 AUTO 店铺缺少授权规则时不补造管理员同意，普通预约走人工，即时预约关闭。全新演示测试库提供有明确范围的示例授权；主预览需店铺在设置页主动配置。
- SOLO 继续由经营者本人受理，不通过普通设置启用或替代所有权审核。
