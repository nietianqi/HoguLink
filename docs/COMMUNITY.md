# 发现 · 社区（P1）

日期：2026-11-02。「发现」升级为社区：顾客提问，店铺、技师、编辑部和其他顾客回答；技师写手记，店铺发动态，编辑部发指南。不新增底部导航，不做私信，所有顾客与经营者内容先审后发。

旧链接兼容：`tab=therapists` → 技师手记，`tab=safety` → 指南；`tab=shops` 仍由页面重定向到 `/shops` 店铺目录，接口层按店铺动态处理。

排序不使用阅读、点赞或"人气"：置顶编辑部内容在前，社区帖子按发布时间倒序，资料卡与指南随后。地区与语言筛选对社区帖子分别按帖子地区／店铺服务地区和原文语言生效；编辑部内容为三语，不受语言筛选影响。

## 角色与规则

- **顾客**：已验证账号才能提问、回复、标记"有用"。公开显示稳定的匿名昵称（如"顾客 3FA2"），不返回账号、姓名或邮箱。每天最多 3 个提问、20 条回复。
- **技师**：所属店铺在「社区」开启"允许本店技师发帖"后，才能写手记和回答问题；每 7 天最多 3 篇手记；配图只能从本人已审核照片中选择（最多 3 张）。技师可设置手记的回复范围：所有已验证顾客／仅服务过的顾客（存在本人已完成订单）／不开放。
- **店铺**：每 7 天最多 3 条动态，五种模板（新项目、新技师、限时优惠、营业通知、门店环境）。新项目和限时优惠必须关联本店当前在售的放松项目，价格从项目实时读取，帖子里不写价格；限时优惠和营业通知必须设置 30 天内的截止日，到期自动下架。配图只能使用已发布的店铺主页照片。店铺对本店技师内容负责，可下架其手记。
- **编辑部**：具有 `supply.write` 的平台员工发布三语内容，立即公开，可置顶。
- 店铺停用、暂停或计费冻结，技师离店、身份或肖像授权失效时，相关帖子与回复自动退出公开展示。
- 提问者可以采纳一条他人的回答（可取消或更换）；采纳的回答排在最前，其后按"有用"数和时间。

## 审核与治理

1. 提交时自动拦截：站外联系方式（电话、LINE／微信等账号、邮箱、链接）和性服务暗示，直接返回错误，不进入公开或审核。联系方式规则在 `@hogulink/contracts/discovery` 的 `communityContactRules`，发帖框的即时提示与服务端拦截同一套规则；价格、预算和日期不会被误判为电话。
2. 自动标记（允许进入审核，提醒审核员注意）：医疗功效用语、外貌评价、行程或住址。询问"腰痛能不能按"属于正常提问，由审核员判断。
3. 顾客、技师、店铺的帖子和回复都先审后发；编辑部回复直接发布。后台「审核 › 社区」按"被举报优先，其余按提交先后"排列，可通过、退回（需写给作者的原因）、隐藏（需原因）、恢复、驳回举报、禁言（0–90 天，0 为解除）。所有操作带版本校验并写审计。
4. 举报：登录用户可举报他人的已公开内容（8 种原因），同一人重复举报不重复计数；3 个不同举报者即自动隐藏，等待审核员恢复或确认隐藏。
5. 不做私信、顾客互相关注和评论区外的联系渠道；联系一律通过订单消息。
6. 店铺与技师发布的内容在卡片上标注"店铺发布／技师发布"（隐性营销规制），编辑部内容标注"编辑部"。

## 接口

完整前缀 `/v1/`。写入沿用来源校验；未登录 401，角色不符 403。

| 方法与路径                                                                                     | 说明                                                                               |
| ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `GET public/discovery?tab=recommended\|questions\|notes\|updates\|guides`                      | 社区帖子并入原内容流，卡片带 `community` 元数据                                    |
| `GET public/discovery/post-…`                                                                  | 详情含 `community.body / replies / closed`，不受浏览筛选影响                       |
| `GET community/posts/:id/viewer`                                                               | 当前账号能否回复及原因、是否作者、已标"有用"、本人待审回复                         |
| `POST community/questions`                                                                     | 顾客提问（每天 3 次）                                                              |
| `POST community/posts/:id/replies`                                                             | 回复（每天 20 次）                                                                 |
| `POST community/posts/:id/accept`                                                              | 提问者采纳／取消 `{ replyId \| null }`                                             |
| `PUT community/replies/:id/helpful`                                                            | 顾客标记有用 `{ helpful }`                                                         |
| `POST community/(posts\|replies)/:id/report \| withdraw`                                       | 举报（8 种原因）／作者撤回、店铺下架本店技师手记                                   |
| `GET community/mine`                                                                           | 本人（或本店、本技师）的帖子与回复及审核状态、原因                                 |
| `GET staff/community`，`POST staff/community/notes`，`PUT staff/community/settings`            | 技师工作区、写手记、回复范围                                                       |
| `GET merchant/community`，`POST merchant/community/updates`，`PUT merchant/community/settings` | 店铺工作区、发动态、技师发帖开关                                                   |
| `GET admin/community`，`POST admin/community/(posts\|replies)/:id/review \| dismiss`           | 审核队列、审核决定、驳回举报                                                       |
| `GET admin/community/mutes`                                                                    | 独立的有效禁言名单，需 `supply.read`；仅含匿名昵称／公开经营者名称、原因和截止时间 |
| `POST admin/community/mutes`                                                                   | 禁言或解除，需 `supply.write`；可带 `expectedUntil` 防止旧名单解除已续期的限制     |
| `GET/POST admin/community/editorials`，`PUT admin/community/editorials/:id`                    | 编辑部内容列表、发布、置顶                                                         |

数据：`communityPosts`、`communityReplies`、`communityVotes`、`communityReports`、`communitySettings`（`store:` 技师发帖开关、`listing:` 回复范围）、`communityMutes`。经营者内容以 `store:`／`listing:` 为作者键，不绑定某个登录账号。后台待办新增 `community`（待审帖子与回复＋仍有未处理举报的内容）。

## 前端

- `/discover`：五个页签；社区卡片显示身份标识、置顶、回答数或截止日；无图帖子为文字卡。右上「提问」「我的帖子」。
- `/discover/post-…`：正文、关联项目（跳转店铺并带上项目）、回复列表（采纳、有用、举报）、回复框（即时提示联系方式与字数）、本人待审回复及退回原因。
- `/discover/ask`、`/discover/mine`：提问页与本人帖子（状态、原因、撤回）。
- 技师工作台「我的资料 › 社区」、店铺后台「社区」、平台后台「审核 › 社区」。
- 演示环境首次启动写入 4 条标注"示例"的冷启动内容（编辑部置顶指南、带店铺回答的提问、技师手记、店铺新项目动态），并为演示店"凪"开启技师发帖；只执行一次。

## 暂不包含

顾客体验分享帖（完成订单后）、放松生活图文帖、等级与徽章、消息页社区通知、信用账号先发后审、推荐排序个性化、图片上传与图片审核、机器翻译。这些属于 P2／P3。
