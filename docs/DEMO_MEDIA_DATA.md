## 拉取代码后导入

先安装依赖并启动本地API和网页，再在项目根目录执行：

```powershell
npm run seed:media
```

脚本默认访问 `http://127.0.0.1:4000`，请求来源为 `http://localhost:3000`。不同端口可通过 `DEMO_API_ORIGIN`、`DEMO_WEB_ORIGIN` 配置。只允许本机、已开放演示登录且明确返回demo的API，正式或staging环境会拒绝导入。

- 六位技师各增加一张相册照片；保留原主照片。照片走技师上传、店铺确认、平台审核的现有流程，演示审核不表示真实身份核验。
- 三家店铺各增加一张封面和三张相册图（封面、氛围细节、已有项目示意图），以及完整三语介绍和本店项目、团队顺序。通过现有店铺主页审核流程发布。
- 首页、店铺目录和店铺详情读取已发布封面，保持原卡片尺寸；技师详情可切换新照片。
- 重复导入保留已有技师媒体、店铺草稿、图片库和已发布内容；修改过主照片、归属或已不可公开的技师不会被覆盖。未改变价格、服务方式资格、门店审核、预约、评价或交易。
- 素材全部上传后才提交主页；中途中断留下的私有素材应在店铺图片库检查，脚本不会覆盖已有内容来强行继续。

## 随仓库提交的数据

- `scripts/fixtures/demo-media-data.json`：六位技师、三家店铺的图片关联和三语内容。
- `scripts/fixtures/demo-media-manifest.json`：12张生成图的提示词、参考图、文件位置和大小。
- `hogulink-web/public/images/demo/`：压缩后的12张JPEG，总体约2MB，单张均低于350KB上传限制。
- `scripts/seed-demo-media.mjs`：可重复运行的导入器，自动退出自己创建的演示会话。

GitHub中保存可重建的测试数据与素材，不提交运行中的SQLite文件、私人证件、会话或密钥。其他电脑导入后会生成自己的媒体ID和加密文件，页面关联保持一致。

验证：`npm run test:demo-media` 检查环境限制、手动资料保护、三语关联与图片可读取性；重复导入应返回新增技师0、店铺0，旧媒体ID和主页版本保持不变。
