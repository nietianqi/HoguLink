# 技师、店铺与下单体验统一优化

2026-10-17，延续 DESIGN.md 的深绿、暖白、石色、衬线标题与清晰费用层级。沿用已有空间图与演示人物插画，没有生成或抓取新的同行人物照片。

## 业务与页面

- 技师详情：面包屑、个人介绍、语言、住宅/酒店接单条件、所属经营主体、按时长的完整费用、预约前须知、同店技师。侧栏可选择项目和真实时段，再带入下单。
- 店铺详情：上门服务品牌展示、公开团队与服务地区数量、受理方式、店铺服务菜单、按语言筛选技师、经营主体披露。默认“不指定技师”，菜单总价不收指名费；指定技师卡片明确包含指名费。
- 服务与时间页：可比较项目总价、指定/不指定技师、即时/指定时间、地区、语言；用日期与时段按钮替换长下拉框，始终显示费用明细和当前选择。
- 结算页：步骤条、实际项目与时长、上门地区、当前报价、酒店限制、支付保障与冻结取消政策。酒店限制使用实际保留人员的接单条件；FREE 不将内部暂时保留的人员展示成已确认技师。
- 修改预约：本人主动释放 CHECKOUT_HOLD 及占用区间，同时作废尚未使用的 AUTHORIZED/METHOD_SAVED 演示支付；接口支持安全重试，禁止释放已提交的预约。返回选择页保留项目、区域、语言和时间供重新确认。
- 地址草稿：同区域修改和语言切换保留字段；换区域清空旧详细地址；酒店限制覆盖不兼容的住宅类型，访客同意不从无关草稿自动继承。条款同意在新预约中重新确认。

## 价格与可约性

公开目录新增 bookingRules，页面按服务端指名费配置估算费用；最终报价仍由服务端计算。时段加载使用条件键与请求取消标记，条件变化立即清空旧可选项，未返回前不能提交。所选时段失效时要求重新选择；失败和空结果都有重查入口。

即时预览检查实际待机有效期、店铺受理能力、语言、所选项目和出发至服务结束的占用区间，返回可用于报价的预计开始时间。FREE 可约性查询使用同店支持该项目的人员，代表技师不支持该 SKU 时不会误判整个店铺没有该项目。指定时间预览仍为原有未来 72 小时窗口。

## 接口增量

| 接口                                            | 增量                                                                         |
| ----------------------------------------------- | ---------------------------------------------------------------------------- |
| GET /v1/public/staff-listings                   | bookingRules.nominationFee、bookingRules.cancellationPolicy                  |
| GET /v1/public/staff-listings/{id}/availability | mode=INSTANT 可查即时可约性；默认保持 SCHEDULED                              |
| GET /v1/public/stores/{slug}/free-availability  | mode、language、offeringId，共同约束同店产能                                 |
| GET /v1/booking-holds/{id}                      | visit：项目名、时长、酒店限制、受理方式、原展示条目；FREE 隐藏人物姓名与图片 |
| DELETE /v1/booking-holds/{id}                   | 仅本人、仅结算保留，原子释放容量与未使用授权；已提交的订单不能通过此接口取消 |

## 验收

- 63 项服务端业务测试与 8 项前端业务规则测试通过；覆盖释放容量/授权、权限、已提交保护、FREE 项目支持、即时出发区间、酒店限制和草稿恢复。
- 12 项浏览器检查通过：详情到下单传递、时长/地区/时间、支付失败与成功、修改释放、地址草稿、语言切换和认证恢复。
- 7 项店铺路径检查通过：语言筛选、FREE 路径与费用、人工店铺即时限制、真实提交后仍为 REQUESTED；测试订单已按店铺原因取消。
- 5 项异常/延迟检查通过：查询失败可重试、重试恢复、切换项目清除旧时段、重新明确选择、空结果可操作。
- 三语言 × 四类页面（技师/店铺/选择/结算）× 1440/1280/390 三种宽度，共 36 种组合通过溢出和运行异常检查。酒店限制在所有结算组合下复查。
- 原 72+90 项 HTTP/SSR 检查通过独立内存 API 完成。反复操作触发了主预览演示顾客的每小时次数限制，未清空用户数据或放宽限制；新增 `npm run smoke:isolated` 可重复运行，写入使用独立内存，SSR 仍验证本机 Web 预览。
- 页面仍为本地演示；正式 PSP、LINE、真实身份与完整法律文本等既有生产依赖未改变。未开展全面性能、读屏或生产负载认证。
