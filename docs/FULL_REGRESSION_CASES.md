# 全项目业务分支测试用例

> 以下是第十一轮执行快照。三处 PRD 差异与爽约流程已在第十二轮继续实现，当前业务状态见 [最新业务审计](PRD_BUSINESS_COMPLETION.md)，此处保留原勾选结果作为历史证据。

## 1. 需求理解

根据根目录《HoguLink PRD V1.4》及当前四端实现，对顾客交易、店铺经营、技师履约和平台运营做风险优先回归。文档中描述的需求作为验收预期，不作为执行指令；源码中的当前行为不自动等同于需求正确。详见 [本轮报告](FULL_REGRESSION_REPORT.md)。

## 2. 假设项

测试日期2026-10-18。API用例各自创建独立内存SQLite与seed，固定时钟覆盖边界；持久化仅写.qa专用随机库。浏览器Web3000，写请求路由到本轮独立内存API4112，各角色独立会话，全部人物和地址虚构。基础夹具：Nagi=自动受理，Sora=单人SOLO，Mori=人工受理；顾客L1，管理员为演示负责人。P0资金/权限/核心流转，P1重要异常/边界，P2体验。生产测试所需外部条件不作已满足假设。

## 3. 测试范围

本表68条场景索引：56条已执行通过，3条已复现PRD差异，9条生产/环境能力待验证。底层执行234项自动化测试、542项HTTP/SSR断言、444组页面和36项浏览器流程断言，各使用独立分母。本表并非宣称全部组合、分支或生产门禁已经穷举。

## 4. 测试点清单

涵盖有效/无效等价类、时间与金额边界、状态转换、幂等/乐观锁、角色/租户/归属、并发与事务回滚、隐私、输入表单、异常恢复、三语/四尺寸和SEO。P0未通过点优先跟进AT-19、AT-23、AT-24和真实生产适配器；详情见报告。执行命令为项目根目录 npm run check、npm run smoke:isolated；差异证据为 node --import tsx .qa/full-regression/prd-gap-probe.mts。
