## 本轮覆盖

- 顾客：发现、技师与店铺详情、四种预约组合、语言/服务/地区匹配、可约时段与交通缓冲、报价冻结、支付保障、订单提交/幂等、取消、消息与改派同意。
- 店铺：MANUAL/AUTO/SOLO、店铺派单与候选资格、团队日历、排班冲突、休息审批、服务价格和上下架、方案计费、分次退款、财务汇总及脱敏导出。
- 技师：任务归属、确认/拒绝/撤回、出发/到达/开始/完成、待机到期、休息申请、阶段性地址权限、私密反馈、SOS 与安全终止。
- 平台：资料审核与并发版本、暂停/恢复、安全处置、限制与申诉、普通与敏感工单、处理人认领/释放/分派/转组、跟进与重开。
- 员工：邀请唯一邮箱、单次与过期激活、密码边界、登录、六岗位权限、业务组限制、账号停用/重置/恢复、旧会话撤销、离岗交接与内部记录隔离。
- 边界：十种订单状态的非法履约事件、15 分钟/30 天报价边界、取消费 120 分钟临界值、响应截止时间、22:00–06:00 住宅首次上门门槛、支付字段篡改、退款取整、并发争抢、事务回滚和 SQLite 重启持久化。
- 接口异常：无效/缺失会话、错误角色与租户、不可信或缺失 Origin、未知路由/方法、严格输入校验、过期权限；浏览器模拟 503 和 401。
- SEO：三语 SSR、canonical/hreflang、工作台与交易页 noindex、robots、五类 sitemap、无效公开条目 404。
