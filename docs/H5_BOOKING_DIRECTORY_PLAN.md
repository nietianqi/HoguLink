# H5 三个选购列表统一方案

日期：2026-10-29。基线：`fba03f3`。

首页保留项目、技师、店铺三种精选入口；完整目录统一归属预约区，服务方式及最终报价在预约链路内确认。

## 路由与入口

| 列表 | 完整目录               | 卡片主操作                                       |
| ---- | ---------------------- | ------------------------------------------------ |
| 项目 | `/{locale}/services`   | 预约此项目 → 主动选服务方式 → 店铺安排或指定技师 |
| 技师 | `/{locale}/therapists` | 查看时段 → 技师详情预约区                        |
| 店铺 | `/{locale}/shops`      | 进店看看 → 店铺主页及本店预约区                  |

原 `/{locale}/discover?tab=shops` 以服务端重定向兼容，保留有效地区、语言、预约方式、服务方式、搜索、排序和分页，剔除店铺目录不支持的时长、预算及交易字段。PC 导航、收藏空状态、指南和发现中的店铺入口同步使用独立目录；发现保留现有内容能力。

## 共同框架与条件边界

- 三个列表使用同一套标题、返回、维度切换和已选条件组件。手机标题与筛选区压缩；PC 保留宽屏筛选能力。
- 切换维度只传地区、服务语言、预约方式及服务方式偏好。搜索词、排序、时长、预算、分页等属于当前列表，不跨对象套用。
- 到店与即时预约组合统一规范为指定时间；到店营业、资源、费用及人员权限继续由现有服务端规则判定。
- 项目保留时长、优惠、排序和完整筛选；技师保留附近估算、时长、交通费、语言及时间等既有能力；店铺仅显示实际支持的地区、语言、方式、搜索和真实排序。
- 店铺目录复用已有卡片、12 家分页及批量统计，不增加编辑内容请求或逐店统计请求。
- 首页“全部”始终保留，不填虚构数量。完整列表的项目数、技师数及店铺数来自当前条件下的实际数据。

## 项目与人员安排

项目弹层先刷新公开供给，再由顾客主动确认上门或到店。即使只有一种方式也不自动选择。之后仅展示该具体 SKU、该方式支持的人员，以及“不指定，由店铺安排”选项。

分别显示店铺安排与指名参考价，店铺安排不收指名费，到店不收交通费。链接携带主动确认结果、真实项目及人员偏好，进入原预约页后保留选择；最终可约性、费用和保留仍由原报价接口决定。同名项目不跨店合并。

店铺列表按最低起价排序时，最低价及对应 SKU 同时考虑有效的上门和到店变体，防止卡片显示到店低价、排序却使用上门价格。未选择指名时，备选指名费明确为“指定后计入合计”。

## 导航与返回

- 三个目录在手机底部统一高亮“预约”。首次默认技师，随后记住当前设备上一次浏览的目录类型。
- 回首页带回对应 `browse` 页签；项目和店铺等入口仍保留当前主题及精选数量，不新增底部导航项。
- 列表条件和滚动位置仅保存在当前标签页。详情链接标记其列表来源；返回时恢复对应列表条件和位置。首页详情卡片另标记首页来源，保持返回首页页签。
- 仅记录经过白名单规范的公开条件和最多 16 个浏览位置。不记录订单、支付凭据、服务地址或报价保留。存储不可用时按正常链接降级。
- 浏览服务方式偏好与预约主动确认分开。目录切换从不携带 `modeConfirmed`、旧时间、支付或保留信息。

## 验证

模型测试覆盖条件隔离、旧地址兼容、到店方式规范、异常存储、返回上下文、滚动键与最低起价；原有服务方式及目录测试继续保留。

`scripts/smoke-booking-browse.mjs` 对三语的三个目录及旧地址做只读 HTTP 验证；`smoke:h5` 覆盖 H5 接口和三语页面。浏览器在独立内存环境检查主动选方式、人员与价格、跨目录条件、返回及手机／PC 布局，不以截图替代库存或交易规则断言。

2026-10-29 验证结果：

- `test:desktop`：169 项通过，包含跨维度条件隔离、返回来源、到店规范及起价对应真实项目的回归。
- `smoke:browse`：306 项通过，包含旧链接重定向、三语目录导航，以及普通／高级技师目录先进入详情预约区。
- `smoke:h5`：303 项通过，写入检查使用独立内存 API。
- 到店流程：105 项通过，覆盖审核、资源、报价、签到、履约、验收和复约；顾客流程：74 项通过，覆盖地址、结算恢复及原店铺售后。
- 工作区类型检查与隔离副本生产构建通过，未改动主预览的构建目录。
- 实际浏览器检查：390px 中文筛选与人员安排、320px 英文项目／店铺、390px 日文项目、1440px PC 技师目录及高级筛选；检查视口均无页面横向溢出。
- 详情返回保留原店铺名称排序和浏览位置，返回首页恢复对应页签，首页底部预约入口保留上次目录类型。项目仅有到店方式时仍要求主动确认。
- 隔离样例中，到店店铺安排价为 ¥6,200、指名价为 ¥6,500，进入预约页后保留实际到店项目和不指名选择。浏览器检查未提交订单，未向主预览写入测试订单。

本地前后端沿用 3000／4000，四端共用同一套网页与 API。没有新增支付、储值或优惠券能力。
