## 连贯的业务路径

- `/:locale/discover`：内容推荐、店铺目录及三篇完整三语指南；指南继续进入真实服务项目或同城店铺。
- 店铺筛选写入网址，返回、刷新和切换标签可保留。地区与语言继续带入店铺菜单、技师卡片和预约；不复制旧时间、保留、支付或订单。当前已不支持所选条件时不提供兜底预约代表，也不静默去掉硬性条件。
- 店铺详情可收藏；`/:locale/account/favorites?type=shops` 可查看和取消收藏。技师收藏仍保留原独立分区。下架、资格失效、无公开授权人员或无可用放松项目的店铺隐藏当前资料，旧收藏仍可移除。
- `/:locale/account/messages` 汇总预约与售后更新，显示事项编号、当前状态、更新时间和服务方累计回复数。私密正文留在有权限的原会话中。
- 点击消息先确认本次看到的状态，再打开对应预约或指定工单。手机直接定位工单详情；多个工单不默认误开最新一笔。失效或无权访问的链接显示错误，待本人从列表明确选择。
- 顾客 H5 底栏为首页、发现、项目、消息、我的；预约和售后仍可从个人中心进入。详情、预约、结算保留各自费用操作栏；工作身份导航继续独立。

## 服务端规则

店铺收藏只接受已验证顾客本人，保存上限100家；同一收藏采用版本核对，冲突不覆盖他端修改。新增收藏时重新核对店铺有效性、收款配置、人员身份/店铺关系/肖像授权/公开状态及已批准的有效放松项目。响应不含 PSP 路由或私有安全联系人。

站内消息从本人订单事实和本人发起工单生成，不读取共用 Outbox 作为用户消息，也不按工单的 `customerId` 推定可见性。技师安全报告、他人订单、工单证据、内部备注、消息正文、地址和支付标识不进入摘要。每个事项按当前版本与收到的回复编号产生摘要标识；已读只确认显示过的那一版。标记过程中若出现新回复（即使同一毫秒），新版本仍未读。重复确认同一版幂等；跨账号无法修改他人回执。

消息按更新时间及事项编号稳定分页，每页20条；未读数量覆盖本人全部事项。批量已读仅针对已加载、实际显示的事项，100条一批；未加载的旧消息不会被一起清除。进入、返回或手动刷新读取更新；徽标同步刷新及已读。此处是本地站内能力，未宣称外部推送已送达。

## 接口

| 方法与路径                                   | 规则                                                                               |
| -------------------------------------------- | ---------------------------------------------------------------------------------- |
| `GET /v1/customer/store-favorites`           | 本人当前收藏；失效行保留可移除的编号和版本，公开资料为空                           |
| `GET /v1/customer/store-favorites/:storeId`  | 本人的 `active / version`                                                          |
| `PUT /v1/customer/store-favorites/:storeId`  | `{version, active}`；版本冲突409、供给无效409、超过100家409                        |
| `GET /v1/customer/inbox?filter=all&cursor=…` | `all / unread / bookings / support`；20条及 `nextCursor / unreadCount`             |
| `POST /v1/customer/inbox/read`               | `{items:[{id,token}]}`，每批1–100条；返回 `marked / stale`，陈旧确认不会吞掉新更新 |

所有接口经过现有认证、身份范围和不缓存规则；写接口沿用来源校验。无效分页游标400，结构校验失败422，未登录401，工作身份403。
