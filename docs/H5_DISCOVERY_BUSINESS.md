# H5 发现业务与接口

2026-10-19，第三十六轮。参考用户提供的发现页截图，以及此前已实际观察的[发现入口](https://yxh5.dongjiaotn.com/#/pages/tabBar/discover/discover)和图文详情。保持既定绿白风格、三语和原有预约规则。

## 顾客闭环

1. 五分类浏览推荐、店铺、指南、技师档案和安心内容。可按内容/作者名称、服务地区与语言筛选，清除筛选后恢复当前分类。
2. 首次读取 8 条，加载更多追加下一页，不重复；供给或筛选改变导致游标失效时，从首批重新读取。错误可重试，无匹配有恢复入口。
3. 卡片进入独立内容详情：作者、图集/前后切换、正文、关联内容、点赞、内容收藏和预约操作。返回保留分类、搜索、地区与语言。
4. 顾客登录后，点赞/收藏跨刷新保存；未登录可阅读，互动进入账号页，安全的站内返回地址保留原详情及筛选。技师收藏、店铺收藏、内容收藏是独立类型；个人中心收藏总数包含三类。
5. 指定作者进入对应公开档案或店铺；技师内容直接进入该技师预约，店铺内容进入其当前菜单，指南进入人员目录。只携带地区/语言，不带旧时段、支付或保留编号。预约页重新查询价格与资格，本轮实测台东区/中文、凪店60分钟总价8,700日元正确带入。

## 数据来源与范围

内容由当前合格的公开技师/店铺资料、自有三语指南构成，使用稳定内容编号和固定排序。店铺/技师需具备可公开的有效肖像、资格、成员关系以及有效的放松项目；停用、暂停、肖像撤回、无有效菜单或不满足地区/语言时不进入相关供给内容流。通用指南不因供给地区筛选而消失。

指南在 `packages/contracts/src/discovery-content.ts` 统一定义，网页和 API 使用同一份内容。共享包新增明确的 discovery/discovery-content 子路径导出，兼容 API 的 NodeNext 与 Next.js 编译。未增加投稿、视频发布或内容管理后台；不把现有公开资料包装为真人故事、公益项目或医疗建议。演示人物、场景与图片继续标注示例/示意。

阅读数是每篇内容的已登录顾客去重阅读人数，重复访问、换语言或刷新不重复累计；匿名阅读不增加个人记录。公开只返回聚合阅读/点赞/收藏数，不返回顾客身份、收据、内部店铺字段或上传证件。

## 接口

| 接口                               | 用途与约束                                                                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `GET public/discovery`             | `tab, search, area, language, limit, cursor`；默认8条，最多20条，搜索80字；游标绑定筛选及当前供给编号，返回 items/total/nextCursor |
| `GET public/discovery/:id`         | 公开作者/图片/正文/统计/关联内容；可带 area/language；已下架或不匹配当前条件返回404                                                |
| `GET customer/discovery/:id`       | 本人 liked/saved/version，其他账号状态独立                                                                                         |
| `PUT customer/discovery/:id`       | version/liked/saved；返回新版本及实际聚合统计；并发旧版本409                                                                       |
| `POST customer/discovery/:id/view` | 本人去重阅读，重复调用只保留一份记录，不改变互动版本                                                                               |
| `GET customer/discovery/saved`     | 本人最多100条已收藏内容，按更新时间降序；下架内容保留可移除的空引用                                                                |

完整前缀为 `/v1/`。个人接口要求已验证顾客会话；访客401，经营角色403。写入保留来源校验，限制每顾客每分钟60次。互动在同一事务内重新检查公开资格，避免下架与写入竞态；最多100条收藏。下架后可清除本人已保存的互动，不能新增赞或收藏。新增 postId/slug/saved/liked 查询索引，聚合使用按内容计数，公开读取不会写入阅读记录。

## 前端与验证

列表/详情/收藏对应 `/:locale/discover`、`/:locale/discover/:postId`、`/:locale/account/favorites?type=content`。列表有请求代次和并发保护；失效游标可恢复；互动冲突后重新读取本人状态。原生横向滚动和图集按钮共用页码，支持减少动态效果设置。首屏卡片与首张大图优先加载，其余图片继续按需读取。

626项后端、75项前端、167项隔离HTTP/SSR、类型检查与生产构建通过；发现模块最终11项复测通过。新增覆盖合格供给、三语检索、游标边界、去重阅读、账号隔离、并发版本、收藏上限、下架清理、公开字段和收藏总数。

浏览器检查108组（三语×320/390/1440×12页面），36组素材复查、24组首屏图片加载复查；没有横向溢出、破图或最终新增控制台告警。实际完成分页8→12、组合筛选、详情返回、收藏/点赞刷新持久化及恢复、收藏列表和技师预约带入；没有创建预约或进入支付。对旧技师/店铺收藏页保留横向分类导航。

本机证据在 `.qa/h5-discovery/`，当前[视觉验收](../design-qa.md)包含源图和实现的同输入完整/局部对照。本轮参考站当前加载不稳定，源视觉采用用户截图和此前真实捕获，不将其加载占位画面当成目标。
