# 手机 H5：项目选择与个人中心

更新：2026-10-18。本轮以现有代码为基础，参考用户提供的[东郊到家 H5](https://h5.dongjiaotn.com/#/)，完成首页快捷区、服务项目、顾客个人中心及设备浏览记录，并衔接既有预约、评价、收藏和售后流程。

## 实际观察与取舍

已在手机尺寸浏览参考站首页、全部项目和未登录个人中心。首页把常用入口、项目卡片和预约操作前置；项目卡片集中展示名称、时长、费用和预约入口；个人中心把订单状态与收藏、足迹、咨询组织成独立入口。项目预约会进入登录页，发现列表受定位限制，因此未验证其登录后支付、人员分配和调度规则。

HoguLink 借鉴上述信息组织，沿用自己的深绿、暖白、细边框和服务规则。所有服务来自当前有效店铺及已开放的放松类项目；费用仍以日元展示，明确服务费、指名费和交通费。优惠、储值、销量、距离和治疗项目没有作为装饰性数据加入。

## 本轮业务与页面

| 入口                                                    | 行为                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [手机首页](http://127.0.0.1:3000/zh-cn)                 | 新增预约、收藏、浏览记录、商户合作四个快捷入口；60/90/120分钟卡片显示当前合格供给的最低含税总价，并带地区、语言、预约类型进入项目列表。                                                                                                                              |
| [服务项目](http://127.0.0.1:3000/zh-cn/services)        | 从项目和店铺开始选择；搜索、地区、语言、预约类型、时长及价格排序可以交叉使用。手机将高级筛选收进底部弹层，取消不应用草稿，应用后写入网址，返回与分享能保留条件。                                                                                                     |
| 项目→人员                                               | 点击时重新读取供给和当前价格，核对所属店铺、资质、肖像授权、服务与语言。即时模式另查当前时段容量；查询失败不会提供未经核对的人员入口。选中技师带入指名模式；也可明确选择店铺安排并免指名费。只带选择条件，仍需重新选时段、建立报价与保留。                           |
| [我的](http://127.0.0.1:3000/zh-cn/account)             | 集中展示待提交预约、进行中、待评价、售后与帮助，提供最近三笔预约、收藏、安全说明和商户合作。数字来自本人订单事实，不是静态占位。                                                                                                                                     |
| 待提交预约                                              | 只包括本人有效、未消耗、尚未成为订单的 checkout hold；展示保留到期、原报价总价和同一个恢复入口。已成立的授权订单不会混入该分区。到期、修改释放或认证失败后移除入口，恢复仍执行原 checkout 校验。                                                                     |
| 进行中与待评价                                          | 进行中入口带入真实订单筛选；待评价直达可评价的本人订单。完成且发生过扣款、未评价或需要修改的记录才计入；待审核、已通过或被移除的评价不作为待评价任务。提交后回到个人中心会更新计数。                                                                                 |
| [浏览记录](http://127.0.0.1:3000/zh-cn/account/history) | 当前设备最多12条、保留30天，仅存公开档案编号与访问时间；去重、清理过期和异常记录，不存姓名、肖像、地址、账号或支付数据。展示时读取当前公开目录，失效资料不继续显示旧肖像。可确认清空；退出账号也清空，并同步其他打开的记录页面。浏览器禁用存储时仍可正常浏览和预约。 |
| 手机导航                                                | 顾客固定四项：发现、项目、预约、我的。收藏、记录和帮助归入“我的”；详情与结算保留专用操作栏。店铺、技师、平台的工作台导航继续按原身份与权限提供。                                                                                                                     |

## 布局与交互

- 手机首页新增的三张项目快捷卡片可在首屏完整看到。390×844实测顶部约566px、底部约676px；其下保留原技师发现列表。
- 项目页最初展开全部筛选会挤出首张卡片，现保留搜索与筛选入口，将高级条件收进原生模态弹层；费用与预约操作可以在手机首屏看到。
- 项目卡片使用“时长图形＋店铺和服务＋完整总价＋选人操作”；没有复制第三方人物图片或品牌素材。
- PC 项目页使用双列卡片与完整筛选行，手机专属首页区与底部导航在桌面隐藏。
- 日语、英语、简体中文均有对应文案；可见手机文本输入和选择框不小于16px，修复了顶部语言控件原先14px的问题。弹层限制焦点、支持键盘进入与 Escape 关闭；查询过程中也可关闭选人弹层，旧请求不会覆盖后一次选择。

## 服务端与数据边界

新增 `GET /v1/customer/overview`，仅已登录顾客本人可读。它在现有到期检查后统计本人未提交保留、有效预约、可评价任务、本人发起的未解决工单及收藏数量，返回最近三笔预约的最小摘要。响应不包含地址、顾客标识、支付路由或技师私有安全报告。工作身份和未登录请求均被拒绝；HTTP响应保持不缓存。

补齐即时容量边界：除服务中的任务外，超过原计划结束时间仍在出发或到达状态的任务，也不会重新进入即时可约容量。公开即时目录、可约查询、报价及保留一致校验；未来预约继续按原日历与缓冲区间判断。

未接入新的定位、追踪、钱包或外部营销服务。原有真实身份、真实支付与通知的生产接入边界继续有效，当前仍是本地演示。
