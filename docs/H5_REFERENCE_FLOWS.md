## 前后端边界

- 展示层组织首页、瀑布流、全屏地区选择、照片预览、导航、本人订单分区与消息分类；所有静态文案三语。
- `GET public/h5/bootstrap` 返回服务地区和未开放能力开关；`GET public/h5/therapists` 做合格供给过滤、当前费用/时段及有界分页。
- 档案、店铺、收藏、地址、顾客账号、消息、订单、工单继续调用既有接口；订单行跳转保留本人授权校验。
- 项目选人重新读取当前目录；由店铺安排免指名费。最终报价、政策、保留、受理、技师确认、履约和用户验收继续以原后端状态机为准。
- 消息首页分类不等于四套已经接通的通知渠道；活动与系统入口是明确未开放状态，在线客服仍是工单，不宣称实时送达。

详见 [接口契约与优惠券设计](H5_FRONTEND_BACKEND_MAP.md)。

## 素材与验证边界

第三十三轮曾保存的 26 个参考站 UI PNG 已于第三十八轮全部删除，导航、快捷入口、消息分类、订单图标与空状态改用 lucide 图标及自绘 SVG，详见[第三十八轮说明](H5_BUSINESS_FEATURES.md)。未保存对方真实人员肖像、私人上传件、追踪图片、品牌标识或字体。

品牌横幅、按摩示意、空预约插画和六张专业人物照片为原创生成；既有休息场景继续复用。新人物照片仅用于演示模式下、slug 与原种子图片同时匹配的档案，不会替换商户上传图片或生产人物。示例档案与店铺保留提示。

本轮验证的是已观察到的页面结构、路由及本项目既有业务对接。参考站后续时段、地址、支付、取消/退款页面未能进入；没有将其标为已核对，也没有在参考站创建订单、充值或变更账号。生产部署、真实支付与通知、实体手机与真实人员资料仍需单独验收。
