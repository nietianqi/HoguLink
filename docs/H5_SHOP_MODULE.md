## 2. 店铺卡片内容（全部来自现有数据）

- 品牌封面与店标：按店铺 ID 稳定分配 5 种配色之一 + 店名首字母，不使用照片，避免让顾客误以为有实体店面（上门服务）。
- 平台审核、限时优惠（存在进行中的店铺优惠时）。
- 评分 / 评价数 / 近 90 天完成单 / 收藏数：`GET /v1/public/store-stats?ids=`。无评价显示「暂无评价」。
- 服务地区（前两个 + 剩余数量）、服务语言（店内已上架技师语言并集）。
- 技师头像（最多 4 个）与人数、受理方式（自动受理 / 店铺确认 / 店主亲自履约）。
- 「店铺安排 · 起」价：最便宜项目的店铺安排总价（含交通费、不含指名费），按当天有效价；仅在公平比较时显示划线原价。
- 排序与原有店铺选择一致：价格从低到高；不按人气或外貌排序。

## 3. 接口

`GET /v1/public/store-stats?ids=a,b`（≤ 50 个，仅已上架店铺；格式错误返回 422）：

- 评分 / 评价数：该店铺已审核通过的体验评价（与店铺页「真实服务评价」同口径）。
- 近 90 天完成单：该店铺 `COMPLETED` 订单（按 `completedAt`，旧记录回退 `updatedAt`）。
- 收藏数：有效的店铺收藏（技师收藏不计入）。

实现与技师统计共用同一个只读聚合（`aggregateStats`），按索引字段分组，不解码评价正文或订单地址。
