# 顾客 H5 配色统一

2026-10-19，第三十五轮。继续参考[用户指定的 H5](https://yxh5.dongjiaotn.com/#/)，保持已有五入口与预约业务，统一顾客手机页面的颜色、字体和控件形态。

## 共用规则

| 用途               | 色值                     | 配对和对比度             |
| ------------------ | ------------------------ | ------------------------ |
| 主按钮、状态标记   | #00865b                  | 白字 4.60:1              |
| 选中项、链接       | #006b49                  | 薄荷底 #e5f8ef，5.94:1   |
| 主按钮悬停         | #006f4c                  | 白字                     |
| 背景、卡片、分隔线 | #f3f6f8 / #fff / #dce9e3 | 浅背景和白卡片           |
| 正文、说明         | #182d25 / #536b63        | 说明在薄荷底 5.21:1      |
| 价格、优惠说明     | #bd4626                  | 白底 5.16:1              |
| 危险操作           | #ab352f / #fff1ef        | 悬停红底白字             |
| 禁用控件           | #5a6b62 / #e5ece8        | 4.71:1，不使用整组透明度 |

中心预约导航使用较亮的 #009d67，19px 粗体白字为 3.49:1，达到大字标准。图片本身保留现有色彩。

## 实现范围

规则集中在 `hogulink-web/src/app/refinement.css` 的 H5 区段。`body:has(.h5-consumer-demo)` 标记顾客/公开页面，主题仅在不超过 760px 的视口生效。旧 `--hl-*` 及短别名在该范围内映射到 H5 变量，挂到 body 的原生弹层也能继承主题。H5 专属样式引用变量时保留原色回退，避免改变桌面目录、设置与权益页面。

覆盖五入口、项目选择、技师/店铺详情、预约、设置、权益、登录入口、客服、地址、订单列表及指南条款。统一圆角主次按钮、12px 内容卡片和三语系统无衬线字体；危险、反色和禁用操作分别定义前景/背景。地区弹层保持浅灰底/白色页头，照片弹层保持透明主体及深色遮罩。
