# H5 技师预约目录（第三十七轮）

预览：[中文](http://localhost:3000/zh-cn/therapists) · [日本語](http://localhost:3000/ja/therapists) · [English](http://localhost:3000/en/therapists)。

## 页面与交互

参考用户提供的东郊 H5 技师列表收起/展开截图，保留 HoguLink 已统一的绿色、薄荷色、白卡片和橙色价格。手机显示搜索/地区入口、可横滑快捷条件、圆形展开按钮、圆形人物照片、可约状态、店铺/语言、真实总价、最早可约时间及预约按钮。小屏卡片约 98px，常规手机约 110px；PC 使用双列卡片。

展开面板位于手机顶部，背景变暗且不可操作。快捷时长、免交通费和即时预约立即应用；“更多筛选”展开地区以外的时长、语言、总价/时段排序、交通费及预约方式。组合条件在提交时一起生效，关闭或 Escape 不提交草稿，再次打开恢复当前实际条件。地区使用已有的全屏地区选择；头像继续打开原照片预览。

搜索支持三语姓名/店铺名及 NFKC 全角归一化。直接切换快捷条件或地区会带上输入框正在编辑的搜索词。结果中的地区、语言、搜索、非默认排序及 120 分钟条件可以逐项移除，也可全部重置。URL 保留有效组合，返回列表不会丢失条件。

点击总价查看项目费、店铺指名费、交通费和合计。费用弹层和人员卡使用相同预约入口；明确传递 `nomination=NOMINATED`、当前 `offering`、当前可约 `start`、`mode`、地区与语言。后续预约仍重新核对资格、规则、时段与最终报价。没有时段时进入档案查看其他时段，不显示虚假可约状态。

## 公开接口

`GET /v1/public/h5/therapists`

| 条件             | 允许值 / 默认值                                      |
| ---------------- | ---------------------------------------------------- |
| `area`           | 现有五个东京服务区，可省略                           |
| `language`       | `ja / en / zh`，可省略                               |
| `duration`       | `60 / 90 / 120`，默认 `60`                           |
| `mode`           | `SCHEDULED / INSTANT`，默认 `SCHEDULED`              |
| `search`         | 姓名或店铺三语搜索，最多 80 字符                     |
| `sort`           | `recommended / price / earliest`，默认 `recommended` |
| **`travel`**     | **新增 `any / free`，默认 `any`**                    |
| `limit / cursor` | 每页最多 20 位，游标绑定完整条件                     |

返回结构沿用 `MobileTherapists`：`items / total / nextCursor / checkedAt`。每项继续包含公开档案、公开店铺、实际项目、店铺指名费、完整总价和实时最早可约时间。

`travel=free` 在选项目之前过滤 `transportFee === 0`，再选择匹配时长的最低总价项目。因此同一技师即使存在更便宜的收费交通项目，也会正确选中符合免费条件的项目；不会先选收费项目再误判此人不符合。停用、未批准、未关联或非放松类项目依然排除。即时预约继续校验值班新鲜度、地区、语言和原店铺受理规则。

页面 URL 不承载分页进度或任何支付/保留时段令牌。每次重新进入从第一页读取；客户端下一页去重、阻止重复请求，条件游标失效时重新读取第一页，网络错误提供可操作的重试。首次服务端读取失败时使用完整页面重试并保留筛选条件。

推荐与价格排序仍只对当前页候选人查询可约时间；最早可约排序需要查询全部匹配候选后排序，这是既有实现的规模限制，本轮没有宣称解决大规模时段排序性能。

## 内容边界

使用实际 JPY 费用、当前可约时段及既有示例肖像；不搬用原站的真人档案、评分、销量、距离、新人/医疗标签。示例环境当前没有免交通费项目且值班状态已过期，相关条件显示真实空结果并提供重置。优惠券仍仅设计接口，储值和真实支付维持暂缓。

## 验证

- 目录后端 8 项测试通过，新增免费/收费同人多项目选择、总价对齐报价、组合条件、游标隔离、停用过滤及即时值班过期测试。
- 前端 78 项测试通过，新增 URL 安全归一化、预约参数及东京跨 UTC 日期标记测试。
- 隔离 H5 HTTP/三语 SSR 共 188 检查通过；写入仅用于一次性内存数据库。
- 生产构建及类型检查通过。
- 实际浏览器 36 组三语 × 320/390/1440px × 列表/展开/高级筛选/费用明细检查，及 6 组免费/即时空结果检查通过。
- 实测“台东区 + 中文 + 90 分钟 + Nagi + 总价排序”筛出 2 位、总价 ¥12,300，费用拆分为 ¥10,800 + ¥500 + ¥1,000；预约页保留所选地区/语言/项目/技师/时段，返回恢复条件。未点击下一步，没有在用户预览中创建保留时段或订单。
- 窗口关闭/Escape 恢复触发按钮焦点和背景滚动；取消语言草稿后重开不会偷偷应用。地区选择、全角搜索和未提交搜索词切换快捷时长均实测。
