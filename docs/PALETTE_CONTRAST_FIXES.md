# 配色与悬停修复（2026-10-19）

延续现有深松绿、暖白、香槟色，修复全局样式覆盖造成的阅读问题。

## 修复内容

- 店铺手机导航的未选中菜单由深色文字改为浅色文字；店铺、技师、平台及通用业务导航共用默认/悬停/选中/焦点配色，选中后保持香槟底与深绿文字。
- 新增明确的`.button.inverse`反色按钮样式，应用于技师当前任务、无任务时的日程入口、店铺详情预约按钮。普通主按钮的悬停规则排除反色按钮；反色按钮悬停/按下仍为暖浅底与深绿文字。
- 修复扩查发现的技师侧栏底部说明与返回入口偏暗，平台审核状态小字偏淡。
- 香槟底色上的金色小字略微加深，服务时长单位及发现页店铺图文标签保持原色调并提高可读性。

只调整样式和按钮类名。业务状态、金额、角色权限、接单、履约和退款逻辑没有修改。
