# 店铺指名费、地区交通费、时段附加费与取消政策

## 营业时间（2026-10-26）

此前可约时段列表固定为 9:00–21:30 开始，而报价接口不校验时间，深夜时间可通过接口直接下单，两端口径不一致。现在店铺可在预约规则中设置指定时间预约的营业时间：

- 日本时间、30 分钟单位；截止时刻本身不可开始（9:00–22:00 即最晚 21:30 开始）；截止早于开始表示跨午夜（如 18:00–4:00）；可设为 24 小时营业。未设置的店铺使用平台默认 9:00–22:00。
- 可约时段列表与报价校验使用同一规则；营业时间外的报价返回 `OUTSIDE_BOOKING_HOURS`。即时预约按上班状态，不受营业时间限制。
- 与指名费、取消政策、时段附加费、地区交通费共用版本和历史；未修改默认营业时间的保存不会写入该字段。保存后对新报价生效，已提交订单不变。

## 地区交通费（2026-10-23）

依据 PRD 第 49 章「交通费：以区域/距离区间预先报价，不在到场后临时收取」。当前平台以服务地区（区）为单位，按区计价；更细的距离区间需要地址定位能力，未在本轮实现。入口：店铺设置 →「指名费与取消政策」中的「按地区交通费」。

| 规则         | 当前行为                                                                                                                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 配置         | 店铺为自己的服务地区逐个设置 0–20,000 日元整数；留空的地区不设置。只能设置本店服务地区，否则返回 `INVALID_AREA`                                                                                                                       |
| 计算         | 预约地区在表中 → 使用表中金额，替代项目交通费；不在表中 → 使用项目自己的交通费                                                                                                                                                        |
| 免交通费项目 | 项目交通费为 0 的「免交通费」项目在任何地区都保持 0，地区表不会让它收费                                                                                                                                                               |
| 报价与订单   | 服务端按顾客地址所在地区计算并冻结在报价 `transportFee`；提交订单时按同一规则复核。改表后未提交的旧报价返回 `SHOP_RULES_CHANGED`；已提交订单的交通费、即时单出发后的交通费取消费、退款余额都按原订单                                  |
| 版本         | 与指名费、取消政策、时段附加费共用版本、历史和审计；相同内容不新增版本；旧客户端不提交该字段时保留原表，提交 `{}` 表示删除                                                                                                            |
| 取消与平台费 | 取消费、爽约费比例和平台服务费都排除交通费，因此不受地区交通费影响；即时单出发后取消仅收原订单冻结的交通费                                                                                                                            |
| 自动受理     | 即时可约预览按所选地区（或授权范围首个地区）的交通费计算总价，与报价一致                                                                                                                                                              |
| 展示         | 选了地区的页面使用该地区交通费：H5 技师目录（含「免交通费」筛选与标签）、服务项目列表、店铺卡片、PC 首页预算筛选与价格排序、技师/店铺详情菜单、下单页。没有选地区的卡片与收藏列表显示项目交通费；详情页和下单页列出店铺的地区交通费表 |
| 再次预约     | 原地区的交通费变化会提示价格已变，需要重新确认                                                                                                                                                                                        |

## 时段附加费（2026-10-23）

依据 PRD 第 35.1 节「时段附加费」、第 49 章费用表和验收项 CP-06（结算页展示含夜间费的完整费用）补齐。入口：店铺设置 →「指名费与取消政策」中的「时段附加费」。

| 规则         | 当前行为                                                                                                                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 配置         | 每店最多 2 段，每段起止时间（日本时间，15 分钟为单位）和金额（100–20,000 日元整数）。结束早于开始表示跨午夜（如 22:00–06:00）。各段不能重叠，可首尾相接                                         |
| 判定         | 只看预约**开始时间**（日本时间）：包含起点、不含终点。服务跨过午夜不重复收取，也不按分钟拆分                                                                                                    |
| 适用         | 指名与店铺安排都收取；只有指名费在店铺安排时为 0。即时和指定时间预约同样适用。指定时间预约的开始时间为 9:00–21:30，因此 22:00–6:00 的附加费主要作用于即时预约                                   |
| 报价         | 服务端按冻结的店铺规则计算，作为单独一行 `timeSurcharge` 计入总价；客户端金额不被采信                                                                                                           |
| 版本         | 附加费属于店铺「指名费与取消政策」版本：保存即推进版本并记录历史，相同内容不新增版本。改动后未提交的旧报价返回 `SHOP_RULES_CHANGED`，需重新报价                                                 |
| 已提交订单   | 冻结报价中的附加费；之后修改或删除附加费不影响原单的扣款、取消费、爽约费和退款余额                                                                                                              |
| 取消与平台费 | 取消费、爽约费的计费基数为「总价 − 交通费」，因此包含附加费；平台服务费基数同样包含附加费、不含交通费（PRD `fee_base`）                                                                         |
| 自动受理     | 店铺授权的单笔金额上下限按含附加费的总价判断。即时可约预览与报价使用同一金额，避免显示可约但报价被拒                                                                                            |
| 展示         | 技师详情、店铺详情的服务菜单说明各段附加费；下单页选定时间后在费用明细中单列「时段附加费」并计入合计；H5 技师目录的价格按所显示的最早时段计算（含附加费），按价格排序仍以不含附加费的基础价排序 |
| 兼容         | 旧客户端保存时不提交 `timeSurcharges` 会保留现有附加费；提交空数组表示删除。旧报价和旧订单没有该字段视为 0                                                                                      |

未覆盖：按区域/距离区间的交通费、服务中延长加时与追加授权，见 [业务逻辑总览](BUSINESS_LOGIC.md) 第 12 节。

以下为 2026-10-19 指名费与取消政策记录。

第三十轮依据 PRD 35.1、48.5、49.4 补齐店铺定价和政策版本。入口：[店铺设置](http://127.0.0.1:3000/zh-cn/merchant?tab=settings)。沿用三语、PC/H5 和深松绿暖白视觉。

## 可配置范围

| 配置       | 当前行为                                                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 店铺指名费 | 0–200,000 日元整数；同店统一。指定技师时计入总价，不指名为 0，顾客同意改派后免除原订单冻结的指名费                             |
| 灵活模板   | 提前 2 小时及更早免费；之后取消为不含交通费金额的 30%；核实爽约为 30%                                                          |
| 分档模板   | 提前 24 小时及更早免费；3 小时至不足 24 小时为 30%；不足 3 小时及开始后为 50%；核实爽约为 50%                                  |
| 自定义     | 免费截止 30–10,080 分钟，截止后比例、临近开始的第二档与爽约比例；第二档起点为 0 时使用单档。界面按半小时输入，接口按整分钟输入 |
| 比例校验   | 0–99%，越临近开始不得降低；爽约比例不得低于取消比例。各百分比均排除交通费                                                      |

模板金额和比例是演示配置，不代表正式合同或法律核定。即时单保留出发前免费、出发后仅交通费、原到达承诺超时免费；店铺原因、拒绝改派等原有免费门槛继续有效。爽约仍须至少两次联系、联系间隔至少两分钟、完整等待十五分钟并经原店铺确认，不能通过自定义政策绕过证据要求。

## 新旧订单与跨端一致性

- 未配置店铺沿用原演示指名费及政策，显示版本 0，不补造商户选择或历史。店铺首次保存后才建立自己的版本。
- 每次有效修改保存完整政策、服务端操作者和时间，推进店铺规则版本；相同配置保存不新增版本。并发修改检查定价版本，冲突时不覆盖他人改动。
- 报价冻结指名费、店铺定价版本和完整取消政策，提交、保留、付款认证均核对当前版本。修改后未提交的旧报价需要重新核对；已提交订单的价格、取消、爽约、改派免指名费、足时履约、验收、退款继续使用原快照。
- 首页总价、预算过滤与排序、技师卡片、技师详情、店铺团队、服务项目选择、下单和最终确认全部读取对应店铺费用；不指名独立保持不含指名费的总价。店铺政策在详情和下单展示，原订单新增可展开的冻结政策。
- 取消按服务端当前时间和冻结分档计算并向下取整到日元。确认跨过费率边界须重新核对费用；取消/爽约不计平台服务费。
- 实际总价继续参与自动受理金额门槛，不用旧全局指名费判断即时可约性。

## 接口与数据

`PUT /v1/merchant/booking-rules`：仅本店 MERCHANT。输入 `version`、`nominationFee`、`templateId=FLEXIBLE_2H|STANDARD_24H|CUSTOM`；CUSTOM 必填 `customPolicy`，其他模板禁止携带自定义字段。接口拒绝自带店铺、操作者、政策版本及额外字段。

`customPolicy` 为 `freeBeforeMinutes/lateFeeBps/nearBeforeMinutes/nearFeeBps/noShowFeeBps`。服务端构建不可修改的即时/爽约保护字段与唯一政策版本。返回 `StoreBookingRules`；店铺工作台新增有效 `bookingRules` 和最近五版 `bookingRulesHistory`。公开店铺提供规则摘要及完整顾客政策，操作人只保留在店铺历史内。目录顶层 `bookingRules` 仅作为旧客户端默认值兼容，当前界面优先使用对应店铺规则。
