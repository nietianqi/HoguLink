## 顾客页面

品牌名片 → 关键信息 → 精选项目与完整菜单 → 本店团队 → 预约区 → 真实评价 → 品牌介绍／相册 → 地区与到店指引 → 费用须知／经营主体。

手机预约区放在团队之后；底部固定“预约本店服务”。PC 右侧固定同一个预约组件，避免两个表单互相覆盖选择。卡片明确价格对应的服务方式；顾客进入预约后主动选择上门／到店。店铺入口默认店铺安排，指名必须明确选择并展示费用。

服务方式未选定前，团队卡片显示“预约制”和视频标记，避免把技师待机当作真实可约。选定上门／到店及项目后，再查询对应人员、床位和营业规则下的真实时段。

上门受理时间、到店营业时间分别说明，内部受理规则转换为顾客能理解的确认提示。地址说明放在页面后段。无可预约到店门店时说明当前提供上门服务，不推断该商户没有任何实体场所。全部统计取真实已审核评价、完成单与收藏；没有统计或读取失败分别处理。

## 配置与发布

- 店铺端独立“店铺主页”入口，展示内容完整度、实际经营统计与当前订阅状态；可预览草稿再提交。
- 上传图片属于本店，服务端重编码、去除元数据并加密保存。未审核图片仅本店和有权限审核人员可访问。
- 图片库可整理未使用素材；草稿或当前公开版引用的图片不能删除，避免整理图片时破坏主页。
- 草稿和公开版本分开；提交后审核，待审核时旧版继续公开。修改待审内容须先撤回，所有写入校验版本。
- Logo、封面、相册、介绍及项目／团队排序都随审核快照发布；推荐只能引用本店记录，公开时继续过滤无资格或已停用供给。
- 平台审核具备独立队列与待办，拒绝说明原因。审核店铺品牌不修改价格、资源或预约政策版本，不影响已提交订单。
- 全部店铺先具备完整、可信的基础主页。年费的既有费率权益保留；未来新增内容容量、视频和经营数据权益时，另外定义有效期、降级与交付规则。历史订单与售后持续可访问。
