# 技师端业务与体验完善

2026-10-18。本轮依据 PRD S01–S08 和既有订单状态机完成独立技师工作台，保留店铺受理服务合同、技师仅确认本人任务的边界。

## 同行参考与取舍

- [Fresha 的不可约时间管理](https://www.fresha.com/help-center/knowledge-base/calendar/18-set-up-and-manage-blocked-time)：借鉴日历区分休息、请假、培训的方式。本项目按 PRD 增加店铺审批，不沿用薪酬设置。
- [Zeel 的人员应用介绍](https://www.va.zeel.com/apply)与[安全说明](https://va.zeel.com/trust-and-safety)：借鉴任务内签到、消息和安全入口。参考官方公开资料，未访问受登录保护的后台，不移植其美国医疗服务与经营安排。
- 视觉沿用项目 `DESIGN.md`：深绿、暖白、鼠尾草和黄铜色，PC 侧栏与双列任务、H5 单列卡片与专用底部导航。

## 本轮完成

| 功能区         | 行为                                                                               |
| -------------- | ---------------------------------------------------------------------------------- |
| 今日工作台     | 真实任务统计、优先待回应任务、接下来日程、待机、店铺紧急联系人                     |
| 我的任务       | 进行中/待回应/已结束/全部筛选，区域/服务/编号搜索，本人任务链接                    |
| 接受与无法服务 | 即时单选择 30/40/45/50/60 分钟到达；结构化原因和补充说明；撤回后仍由店铺安排改派   |
| 履约           | 出发→到达→开始→完成；完成前复核并说明演示扣款及隐私变化；旧版本失败后刷新任务      |
| 地址与消息     | 确认前、结束后隐藏详细地址；有效履约阶段展示地址与任务消息；刷新保留消息草稿       |
| 日程           | JST 日期选择、七日切换、任务和获批休息、前后各 30 分钟交通缓冲说明                 |
| 休息申请       | 休息/请假/培训→店铺审批→共享日历占用；技师撤回待审批申请，店铺拒绝或解除已批准时段 |
| 待机           | 四小时有效，开始/延长/关闭，资格和旧状态校验；关闭不取消既有任务                   |
| 资料           | 本人简介、语言、区域、归属核验与服务；资料变更联系店铺审核                         |
| 安全           | 任务内 SOS 本地记录、安全终止、非公开顾客反馈、安全中心入口                        |

休息申请提交时检查现有预约、交通缓冲、禁约时间及重复待审批申请。**待审批不占用时段**。批准时在事务中重新检查资格、时间、冲突和版本，通过数据库忙碌区间约束防止与预约并发成功。开始时仍待审批的申请自动过期。所有待审批申请和最近 100 条历史可读取，技师界面可展开全部返回记录。

技师只读取自己的归属、任务、日程、申请和安全事件摘要；其他技师、店铺不能读取或审批本人申请。响应不含店铺支付路由和经营财务。统计展示次数及完成服务时长，未把订单金额当作个人收入。

## 接口与代码

- 独立 API 服务 `staff.ts` 经既有事务和清理任务运行；`TimeOffRequest` 为共享契约。
- Web：`staff-workspace.tsx`、`staff-model.ts`、`staff-i18n.ts`、`staff.css`。路径 `/{locale}/staff?tab=overview|tasks|schedule|profile`，任务可附 `booking` 参数。
- 店铺团队日历增加审批卡片；批准后复用不可约时间与预约冲突机制。保持原任务接口兼容，待机写入可附 `expectedAt`。

## 验收

- `npm run check`：82 项 API 测试、14 项前端规则测试，共 96 项，类型检查与生产构建通过。
- `npm run smoke:isolated`：预约 72、售后 90、店铺 53、技师 74，共 289 项 HTTP/SSR 检查，写入独立内存 API。
- 浏览器：3 语言 × 4 功能区 × 320/390/768/1440 宽度，共 48 组；安全中心 3 语言 × 390/1440，共 6 组。54 组正常响应，无页面脚本异常或横向页面溢出。
- 实际操作：40 分钟到达、任务消息、出发/到达/开始、SOS 本地记录、取消完成复核、确认完成及地址隐藏；手机休息申请→店铺批准→技师日程同步；任务历史筛选。
- 补充交互：确认任务后填写身体原因并撤回，由店铺重新安排；安全终止取消任务并隐藏地址；320px 三语到达时间弹窗无溢出，Escape 关闭后恢复页面滚动。
- 写入测试通过单独内存 API，未写入主 SQLite。截图见 `.playwright-mcp/staff-*.png`。
