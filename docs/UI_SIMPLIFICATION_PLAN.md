## 3. 五条原则

每次改页面前先对照这五条。

- **一屏一件事**：每页只有一个主行动。首页是「开始预约」，详情页是「选择时间」，下单页是「确认」。
- **三秒看懂**：卡片只放做决定需要的信息：谁、多少钱（含什么费用）、最早什么时候能来。其余放进详情。
- **克制**：五档字号，最小 12px。一个品牌深绿、一个价格红，其余都是中性色。每张卡片最多 2 个标签。
- **留白代替线框**：少用边框和底色块，靠间距和字重区分层级。「大气」主要来自这里。
- **H5 与 PC 同构**：同样的结构、同样的组件。PC 只是网格更宽、一行放更多，不另做一套内容。

## 4. 信息架构

顾客的主线：找人或找店 → 选时间 → 下单 → 看订单 → 消息和售后。导航保持五个，重新分工。

| 导航 | 负责                                                                            | 移出                               |
| ---- | ------------------------------------------------------------------------------- | ---------------------------------- |
| 首页 | 开始预约，加精选：限时优惠、同城店铺、推荐技师                                  | 完整目录、招商、浏览记录、收藏入口 |
| 发现 | 内容：预约指南、安心服务、店铺动态                                              | 店铺列表（并入预约）               |
| 预约 | 唯一的选购入口：「技师｜店铺｜项目」切换 + 一条筛选栏（地区、时长、语言、时间） | —                                  |
| 消息 | 订单消息、活动消息                                                              | —                                  |
| 我的 | 订单、收藏、浏览记录、设置，以及「商户入驻」入口                                | —                                  |

项目去重：按项目名合并，例如「舒缓放松 · 60 / 90 / 120 分钟 · 3 家店可约 · ¥8,200 起」，点进去再选店或选人。

## 6. 卡片与页面模板

卡片规范影响面最大，先定下来，所有列表共用。

- **技师卡三行**：姓名和认证 / 评分 · 近 90 天单数 · 所属店铺 / 价格（写明含什么）+ 最早可约 + 一个按钮。语言和标签放进详情或筛选。
  - 示例：`葵 [已核验]` / `暂无评价 · 近 90 天 5 单 · 凪 · 东京` / `¥8,700 / 60 分钟 · 今天 20:00 起可约 · [预约]`（价格含指名费与交通费）
- **店铺卡**：店标、店名、一行事实（地区、技师人数、受理方式）、起价、「进店」。
- **项目卡**：项目名、可选时长、几家店可约、起价。同名项目只出现一次。
- **标签**：每张卡最多 2 个，优先级：限时优惠 > 可即时上门 > 免交通费。
- **详情页（技师 / 店铺共用）**：身份与数据 → 价目 → 评价 → 须知 → 底部固定栏（价格 + 「选择时间」）。法律与经营信息默认折叠，标题保留「特定商取引法に基づく表記」。
- **下单三步**：
  1. 选时间：日期、时段；价格摘要固定在底部。
  2. 填地址：常用地址一键选；酒店需房号与许可。
  3. 确认：金额、取消政策一句要点，可展开全文。

## 7. 视觉规范：方向 B

深绿做品牌，米白做底，价格红只用于价格。所有页面只从这些变量取值。

## 10. 不变的底线

本轮只改展示和结构，以下业务规则一律不动。

- 只显示真实数据：评分、单数、收藏来自已审核评价、已完成订单和真实收藏；没有就写「暂无评价」。
- 不做「新人」「人气」「颜值」类标签，不按外貌或人气排序。
- 划线原价按二重価格表示规则：原价满 28 天，且近 56 天优惠天数不超过一半才显示。
- 定位只在设备上计算，服务器只收到区名。
- 价格写清是否含交通费、指名费；报价、扣款、取消规则不在本轮改动范围。
- 不复制参考站的图片、文案、数据或品牌。
